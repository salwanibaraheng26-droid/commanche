บทที่ 1

How to Log in (การเข้าสู่ระบบ Comanche)

ขั้นตอนการเปิดโปรแกรม ป้อนรหัสผ่าน และเข้าสู่หน้าหลักของระบบสำรองห้องพัก

1
เปิดโปรแกรม Comanche และกรอกข้อมูลเข้าสู่ระบบ
เปิดโปรแกรม Comanche Front Office System แล้วกรอก Username และ Password ที่ได้รับมอบหมายจากทางโรงแรม จากนั้นกด OK
🔍 คลิกเพื่อขยายภาพ
รูปที่ 1.1: หน้าต่าง Login กรอก User name, Password และเลือกภาษา Default
2
เลือกเมนู Reservation และคลิก Booking
เมื่อเข้าสู่ระบบเรียบร้อย ให้สังเกตแถบเมนูด้านบน แล้วคลิกที่แท็บ Reservation จากนั้นคลิกปุ่ม Booking ที่เมนูด้านซ้ายเพื่อเข้าสู่หน้ารายการจอง
🔍 คลิกเพื่อขยายภาพ
รูปที่ 1.2: ตำแหน่งลูกศรชี้ที่แท็บ Reservation (ด้านบน) และปุ่ม Booking (ด้านซ้าย)
บทที่ 2

How to Create a Reservation (การค้นหาและบันทึกข้อมูลการจอง)

ขั้นตอนการสืบค้นบุ๊กกิ้ง การเปิดหน้า Guest Booking และการตรวจสอบข้อมูลสำคัญ

💡
หลังจากคลิก Booking ระบบจะแสดงหน้าค้นหารายการจอง (Reservation Search) สามารถค้นหาได้หลากหลายรูปแบบ เช่น ใส่ชื่อแขก (Guest name), หมายเลขการจอง (Reference # / RSVN #) หรือวันที่เช็คอิน (Arrival)
1
ค้นหารายการจองและดับเบิลคลิกเพื่อเข้าหน้า Guest Booking
พิมพ์ข้อมูลในช่อง Search text (เช่น หมายเลขบุ๊กกิ้ง OTA หรือชื่อแขก) จากนั้นคลิกปุ่ม Search เมื่อผลลัพธ์ปรากฏในตาราง ให้ดับเบิลคลิกที่แถวรายการจองนั้น
🔍 คลิกเพื่อขยายภาพ
รูปที่ 2.1: การสืบค้นรายการจองจาก Search text และการดับเบิลคลิกเพื่อเข้าหน้า Guest Booking
2
กรอกข้อมูลบังคับ 5 จุดสำคัญ (ข้อมูลที่ต้องกรอก)
เมื่อเปิดหน้า Guest Booking ให้ตรวจสอบและกรอกข้อมูลในจุดที่มีเครื่องหมายดอกจันสีส้ม/กรอบสีแดงให้ครบถ้วน:
📌 รายการข้อมูลที่ต้องกรอกในหน้า Guest Booking
ชื่อช่องข้อมูล (Field) คำอธิบายหน้าที่ ตัวอย่างการกรอก
Nationality รหัสสัญชาติของผู้เข้าพัก T03 (ตามสัญชาติในพาสปอร์ต/OTA)
CTR. รหัสประเทศย่อ 3 ตัวอักษร THA
Bk Country ประเทศต้นทางของบุ๊กกิ้ง THA หรือประเทศของเอเจนต์
Remark หมายเหตุระบุประเภทห้อง อาหารเช้า ราคา และวิธีชำระ ดูรายละเอียดตามโครงสร้างในบทที่ 3
Attachments ลิงก์สำหรับแนบเอกสาร Booking Confirmation (PDF) คลิกเพื่ออัปโหลดไฟล์ตามบทที่ 5
🔍 คลิกเพื่อขยายภาพ
รูปที่ 2.2: จุดสำคัญที่ต้องกรอกในหน้า Guest Booking (มีสัญลักษณ์ดอกจันสีส้มชี้กำกับ)
3
ตรวจสอบความถูกต้องของข้อมูล (ข้อมูลที่ต้องตรวจสอบ)
ก่อนทำการบันทึกข้อมูลทุกครั้ง นักศึกษาฝึกงานต้องเทียบข้อมูลในหน้าจอ Guest Booking กับใบยืนยันการจอง (Booking Confirmation) ทั้ง 10 จุด ดังต่อไปนี้:
ช่องข้อมูล (Field Name) ความหมาย / สิ่งที่ต้องตรวจสอบ สถานะในระบบ
First Name ชื่อจริงของผู้เข้าพัก (สะกดตรงตามเอกสาร) CRISTINA
Last Name นามสกุลของผู้เข้าพัก ERIKSSON
Nationality สัญชาติของแขก T03
Country / Bk Country ประเทศของผู้เข้าพัก THA
Arrival วันที่เช็กอิน (วัน/เดือน/ปี ค.ศ.) 05/01/2027
Departure วันที่เช็กเอาต์ (วัน/เดือน/ปี ค.ศ.) 07/01/2027
Adult / Child จำนวนผู้ใหญ่และจำนวนเด็ก Adult 3 / Child 0
Room Type ประเภทห้องพัก (เช่น JSK, JST, DLK) JST
Daily Rate ราคาห้องพักต่อคืน 19,633.60

🔍 คลิกเพื่อขยายภาพ
รูปที่ 2.3: หน้าต่าง Guest Booking พร้อมไฮไลท์สีเหลืองในช่องข้อมูลที่ต้องตรวจสอบ
บทที่ 3

How to Add Remarks (การเพิ่มหมายเหตุการจอง)

มาตรฐานการเขียน Remark ย่อในระบบ Comanche เพื่อระบุประเภทห้อง อาหารเช้า ช่องทาง และราคา

📖 ความหมายและวัตถุประสงค์ของ Remarks

Remarks คือ หมายเหตุที่ใช้บันทึกรายละเอียดเพิ่มเติมของการจอง เพื่อให้แผนก Reservation, Front Desk และ Accounting เข้าใจตรงกัน ประกอบด้วย: ประเภทห้องพัก (Room Type) · อาหารเช้า (Breakfast) · ช่องทางการจอง (Source/Agent) · วิธีการชำระเงิน (Payment) · ราคาต่อคืน และราคารวมทั้งหมด

บทที่ 4

How to Set up Billing (การกำหนดข้อมูลการเรียกเก็บเงิน)

การตั้งค่าผู้รับผิดชอบค่าใช้จ่ายในระบบ Folio สำหรับแขก หรือ Company/Agent

📖 วัตถุประสงค์และคำศัพท์ใน Billing Setup

Billing Setup ใช้สำหรับ: กำหนดผู้รับผิดชอบค่าใช้จ่ายของรายการจอง เช่น ค่าห้องพักจะเรียกเก็บจากเอเจนต์ (Company/Agent) หรือเก็บจากผู้เข้าพัก (Guest) โดยตรง

คำศัพท์ ความหมาย / การใช้งานในระบบ
Billing Setup การกำหนดข้อมูลและข้อตกลงในการเรียกเก็บเงิน
Company / Agent บริษัท ตัวแทนจำหน่าย หรือ OTA (เช่น Agoda, Expedia) ที่เป็นผู้จ่ายค่าห้อง
Room Charge (Code 100) ค่าห้องพักสำหรับคืนที่เข้าพัก
ABF (Code 200) ค่าอาหารเช้า (American Breakfast)
1
คลิกไอคอน Billing Setup ที่แถบเครื่องมือด้านซ้าย
ในหน้า Guest Booking ให้เลื่อนสายตาไปที่แถบเครื่องมือไอคอนด้านซ้าย แล้วคลิกที่ไอคอนเครื่องคิดเลข/เครื่องบันทึกเงินสด Billing Setup
🔍 คลิกเพื่อขยายภาพ
รูปที่ 4.1: วงกลมสีแดงและลูกศรชี้ที่ไอคอน Billing Setup
2
คลิกไอคอนกระดาษสีขาว เพื่อสร้าง Folio ใหม่
เมื่อหน้าต่าง Billing Setup ปรากฏขึ้น ให้คลิกที่ไอคอน กระดาษสีขาว (New) เพื่อเปิดแท็บ Folio สำหรับเอเจนต์ (Folio 2)
🔍 คลิกเพื่อขยายภาพ
รูปที่ 4.2: ตำแหน่งลูกศรชี้ที่ไอคอนกระดาษสีขาว (New Folio)
3
เลือก Company/Agent และเพิ่มรหัสค่าใช้จ่าย (Code)
1. ติ๊กที่ช่องวงกลม Company/Agent (หมายเลข 1)
2. คลิกในช่องสีขาวใต้หัวข้อ Code และคลิกไอคอนกระดาษสีขาว (หมายเลข 2) เพื่อเพิ่มรายการค่าใช้จ่าย
🔍 คลิกเพื่อขยายภาพ
รูปที่ 4.3: หมายเลข 1 (ติ๊ก Company/Agent) และ หมายเลข 2 (คลิกกระดาษสีขาวล่าง Code)
4
ตรวจสอบรายการ 100 Room Charge / 200 ABF และกดปุ่มย้อนกลับ
เมื่อใส่ Code 100 Room Charge และ Code 200 ABF เรียบร้อยแล้ว ให้คลิกที่ไอคอนประตูสีแดง Exit (มุมขวาล่าง) เพื่อบันทึกและกลับสู่หน้าหลัก
🔍 คลิกเพื่อขยายภาพ
รูปที่ 4.4: รายการค่าใช้จ่ายที่ตั้งค่าสำเร็จ และกรอบสีแดงเน้นปุ่มประตูสีแดงที่มุมขวาล่าง
บทที่ 5

How to Attach Reservation Files (การแนบไฟล์เอกสารการจอง)

การอัปโหลดไฟล์ Booking Confirmation (PDF) เข้าสู่ระบบ Comanche เพื่อใช้อ้างอิง

📎
วัตถุประสงค์ของการแนบไฟล์ (Attachments): ใช้สำหรับแนบไฟล์ Booking Confirmation หรือเอกสารยืนยันการจองของผู้เข้าพักจาก OTA/Agent เข้าสู่ฐานข้อมูลระบบ Comanche เพื่อให้แผนกที่เกี่ยวข้องสามารถเปิดตรวจเอกสารต้นฉบับได้ตลอดเวลา
1
คลิกที่ลิงก์ Attachments ในหน้า Guest Booking
ในหน้า Guest Booking ใกล้กับกล่อง Remark ทางด้านขวา ให้คลิกที่ข้อความสีฟ้า Attachments
🔍 คลิกเพื่อขยายภาพ
รูปที่ 5.1: วงรีสีแดงและลูกศรชี้ที่ลิงก์ Attachments
2
กดปุ่ม Browse... เพื่อเลือกไฟล์จากเครื่องคอมพิวเตอร์
ในหน้าต่างป็อปอัป Reservation Attachments ให้กดปุ่ม Browse... เพื่อค้นหาตำแหน่งโฟลเดอร์ที่เก็บไฟล์ในเครื่อง
🔍 คลิกเพื่อขยายภาพ
รูปที่ 5.2: วงรีสีแดงชี้ที่ปุ่ม Browse... ในหน้าต่าง Reservation Attachments
3
เลือกไฟล์ PDF บุ๊กกิ้งที่ต้องการ แล้วกดปุ่ม Attach
1. เลือกไฟล์เอกสาร PDF ของการจอง เช่น AGO-1055779594.pdf
2. ตรวจสอบว่าที่อยู่ไฟล์ปรากฏในช่อง Current file attachments แล้วคลิกปุ่ม Attach เพื่ออัปโหลดเข้าสู่ระบบ
🔍 ซูมภาพ
รูปที่ 5.3: เลือกไฟล์ PDF ที่ต้องการ
🔍 ซูมภาพ
รูปที่ 5.4: กดปุ่ม Attach ไฟล์จะเข้าสู่ระบบ
บทที่ 6

How to Create a New Booking (การสร้างรายการจองใหม่)

ขั้นตอนการเปิดระบบ ค้นหา Agent สร้างรายการจองใหม่ และบันทึกข้อมูลผู้เข้าพักในระบบ Comanche

💡
คำอธิบายการใช้งาน: ใช้สำหรับสร้างรายการจองใหม่ของผู้เข้าพักในระบบ Comanche กรณีที่ยังไม่มีข้อมูลการจองอยู่ในระบบ โดยบันทึกข้อมูลผู้เข้าพักและรายละเอียดการจองให้ตรงกับ Booking Confirmation
1-2
เปิดโปรแกรม Comanche และเข้าสู่เมนู C/A Book
1. เปิดโปรแกรม Comanche ใส่รหัสประจำตัวผู้ใช้ระบบ
2. ไปที่หัวข้อ Reservation เลือกหัวข้อ C/A Book
🔍 คลิกเพื่อขยายภาพ
รูปที่ 6.1: เปิดโปรแกรม Comanche และไปที่หัวข้อ Reservation เลือกหัวข้อ C/A Book
3
ค้นหาชื่อ Agent หรือบริษัทตัวแทนการจอง
3. กรอกชื่อ Agent หรือบริษัทตัวแทนการจองในช่องค้นหา (เช่น STAYLAH) แล้วคลิก Search
🔍 คลิกเพื่อขยายภาพ
รูปที่ 6.2: กรอกชื่อ Agent หรือบริษัทตัวแทนการจองในช่องค้นหา แล้วคลิก Search
4
คลิก New Booking เพื่อสร้างรายการจองใหม่
4. เมื่อระบบแสดงหน้ารายการจองของ Agent ที่เลือก ให้คลิก New booking เพื่อสร้างรายการจองใหม่ของผู้เข้าพัก
🔍 คลิกเพื่อขยายภาพ

Room Type & Adult/Child Guide (การเปลี่ยนประเภทห้องพักและจำนวนผู้เข้าพัก)

🔍 คลิกเพื่อขยายภาพ

🔍 คลิกเพื่อขยายภาพ
รูปที่ 8.2: เลือกช่อง Room Type เพื่อเปลี่ยนประเภทห้องพัก

Child Policy & Additional Charges (นโยบายการเข้าพักสำหรับเด็ก)

เกณฑ์ช่วงอายุ อัตราค่าบริการเสริม และข้อกำหนดการเปลี่ยนสถานะในระบบ Comanche

อายุ 0–4 ปี
เข้าพักโดยไม่มีค่าใช้จ่าย

อายุ 5–11 ปี

เด็กอายุ 5–11 ปี มีค่าใช้จ่ายเพิ่มเติมตามช่วงฤดูกาล ดังนี้

  • High Season : 300 บาท/คน/คืน
  • Low Season : 200 บาท/คน/คืน
อายุ 12 ปีขึ้นไป
คิดอัตราค่าบริการในอัตราผู้ใหญ่ (Adult)
